一、今天上首页的推荐

1. Cohere — 免费 evaluation/trial API key

  • 是什么：Cohere 官方限速文档写明提供两类 API key：evaluation key 免费但用量受限，production key 付费且限制宽松得多；试用（trial）key 每月限 1,000 次 API 调用，Command A / A+ / A Reasoning / A Translate / A Vision、Command R / R+ / R7B、North Mini Code 等模型试用限速均为 20 req/min
  • 能拿到：免费试用 key：每月 1,000 次 API 调用，多数对话模型 20 req/min
  • 领取条件与限制：在 dashboard.cohere.com/api-keys 创建 trial 或 evaluation key，仅供开发评估，生产用途需换 production key；Command A+、Command A Reasoning、Command A Translate、Command A Vision 的生产限速需联系 sales@cohere.com；其他端点试用限速另算（Embed 2,000 inputs/min、Audio Transcriptions 5 req/min、EmbedJob 5 req/min、Rerank 10 req/min、Parse 500 req/min）
  • 截止：官方未写活动截止日；1,000 次调用是按月计算的上限，不是限期活动
  • 核验日期：2026-10-03
  • 官方入口：https://docs.cohere.com/docs/rate-limits
  • 上屏文案：每月 1000 次调用，多数模型 20 次/分，仅开发评估（值表：1000 次）

2. Kimi API 开放平台 — 文件内容抽取/存储接口限时免费

  • 是什么：Kimi API 开放平台官方定价页在计费逻辑里写明：文件相关接口（文件内容抽取、文件存储）限时免费，只上传并抽取文档时文件接口本身不产生费用
  • 能拿到：文件内容抽取与文件存储接口调用费为 0
  • 领取条件与限制：只覆盖文件内容抽取与文件存储两个接口本身的调用费；把抽取出的文档内容作为 Input 传给模型时，文档内容仍按量计费；官方未写该限免的截止日
  • 截止：官方定价页未写截止日
  • 核验日期：2026-10-03
  • 官方入口：https://platform.kimi.com/docs/pricing/chat
  • 上屏文案：文件抽取与存储接口限免，文档喂模型仍计费（值表：0 费用）

3. 腾讯混元大模型 — 混元生文首次开通免费 100 万 tokens（1 年有效）

  • 是什么：首次开通腾讯混元大模型服务后，混元生文以一次性免费资源包形式发放免费额度：Hunyuan-a13b 共 100 万 tokens 共享消耗，Hunyuan-role-latest、Hunyuan-translation、Tencent HY Vision 等其余混元生文模型各 100 万 tokens；结算时按免费资源包 > 付费资源包 > 按量后付费的顺序扣减
  • 能拿到：混元生文模型 100 万 tokens 免费额度，1 年有效
  • 领取条件与限制：需先通过腾讯云个人或企业实名认证；首次在混元大模型单击「立即使用」才发放，且是一次性免费资源包；欠费或因违规停服期间不能继续享受免费额度，服务重新开启后才可继续；免费资源包耗尽或到期不会自动转入后付费，未主动在控制台开通后付费会出现计费异常提示
  • 截止：免费资源包有效期 1 年，自开通服务之日起算，1 年内未使用完过期作废；官方未写领取截止日
  • 核验日期：2026-10-03
  • 官方入口：https://cloud.tencent.com/document/product/1729/97731
  • 上屏文案：实名后首次开通发一次性额度，1 年有效（值表：100 万）
